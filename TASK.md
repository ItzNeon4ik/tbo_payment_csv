# Задание: Импорт платежей ТБО

## Цель

Написать программу на Python, которая импортирует платежи из CSV-файлов в базу данных без дублей.

---

## Входные данные

CSV-файлы в папке.

Формат:

```csv
payment_date,source,payer,account_number,amount,external_id
2026-05-01,kaspi,Иванов И.И.,123456,2500,INV-001
```

---

## Что должна делать программа

- найти все CSV-файлы в папке;
- прочитать строки;
- проверить корректность данных;
- сохранить платежи в БД;
- не сохранять дубли (внутри файла и между файлами);
- вывести итоговый отчёт.

---

## Валидация

Ошибка, если:

- нет даты;
- нет источника;
- нет лицевого счёта;
- сумма пустая / не число / ≤ 0.

Ошибки не должны останавливать выполнение.

---

## Дедупликация

Если `external_id` есть:

source + payment_date + account_number + amount + external_id

Если нет:

source + payment_date + account_number + amount

---

## Хранение

- использовать БД (например SQLite);
- обеспечить уникальность платежей.

---

## Отчёт

Пример:

Обработано файлов: 3  
Всего строк: 120  
Добавлено: 95  
Дублей: 20  
Ошибок: 5  

---

## Требования

- Python;
- запуск одной командой;
- структура проекта — на усмотрение;
- есть инструкция по запуску.
