# Тестовые CSV для задания импорта платежей ТБО

Файлы покрывают кейсы:
- корректные платежи;
- дубли внутри одного файла;
- дубли между файлами;
- пустой external_id;
- некорректные строки;
- одинаковый платёж из разных источников;
- лишние пробелы и спорные форматы суммы;
- пустой файл.

Ожидаемая логика дедупликации:
- если external_id заполнен: source + payment_date + account_number + amount + external_id;
- если external_id пустой: source + payment_date + account_number + amount.

Важно: файл `07_spaces_and_formatting.csv` специально содержит спорные значения.
